# Common-Wealth-Job-Simulation

## Overview

This repository documents my participation in the **Commonwealth Bank Cybersecurity Job Simulation** on Forage, focusing on cybersecurity awareness, secure password practices, incident response, and security recommendations.

## Deliverables
* CommonWealth Forage Job Simulation Completion certificate
* The financial dataset ingested into splunk SIEM for  fraud security analysis
* A screenshot of splunk analysis in action
* The fraud detection dashboard statistical analysis from splunk SIEM.
* A sample infographics describing good password practices to the employees at CommonWealth to prevent similar incidents in future.
  
## Skills Gained

* Cybersecurity awareness and risk identification
* Secure password management
* Incident response fundamentals
* Security analysis and documentation


## Disclaimer

This repository contains educational simulation work and does not represent access to Commonwealth Bank’s internal systems.
